# 灾后 72 小时

在虚构小镇的灾后 72 小时中，观察消息如何影响居民判断，用有限干预体验信息辨识、协作与资源选择的连锁反应。

[打开游戏](https://w88856678-rgb.github.io/disaster-72h/)

## 适合谁

- 喜欢策略与模拟游戏的玩家：体验居民之间的信息传播和不同选择带来的结局。
- 教育与活动组织者：把虚构情境作为信息辨识、沟通和协作讨论的材料。
- 对多智能体交互感兴趣的人：观察居民认知、记忆与行为之间的联系。

## 可以做什么

- **推进 72 小时情境**：跟随灾害事件发展，观察小镇状态和居民的变化。
- **查看居民认知**：开启“AI 认知透视”，了解居民当前相信什么及其记忆。
- **做出有限干预**：在干预额度内选择核实消息、公开广播等行动，或继续观察。
- **关注资源与协作状态**：观察资源变化、居民协作和信息失真造成的影响。
- **回看最终结局**：在 72 小时结束时查看小镇结果，讨论关键选择。
- **体验可选 AI 台词**：云端 AI 可为虚构角色生成对话，未配置或异常时保留本地规则。

## 如何使用

1. 打开游戏并阅读规则，了解当前目标、资源与干预额度。
2. 查看居民信息，选择干预或等待，推进时间并观察事件变化。
3. 结合认知透视和最终结局，回顾哪些消息与行动影响了居民。

## 游戏与 AI 边界

角色、事件和结果属于虚构游戏情境，可用于讨论信息传播与协作，不提供现实应急救援服务或专业灾害处置指导。

云端 AI 启用后为虚构角色生成台词；游戏行动与判定仍由本地规则决定。未配置或异常时自动保留本地规则。
